## Project Overview

This repository contains the development of a responsive website for a Seventh-day Adventist Church. The purpose of the website is to provide visitors and church members with easy access to church information, ministries, upcoming events, Bible study registration, online giving, and contact information through a modern and user-friendly interface.

The website is being developed using HTML5, CSS3, and JavaScript while following responsive web design and accessibility principles.

---

## Website Goals and Objectives

### Goals

- Develop a responsive and accessible church website.
- Improve communication between the church and the community.
- Provide information about church ministries and services.
- Allow visitors to learn more about the church and its beliefs.
- Create an easy-to-navigate website for all users.

### Objectives

- Present church information clearly.
- Display upcoming events and announcements.
- Provide Bible study registration.
- Share ministry information.
- Include contact details and location information.
- Ensure compatibility across desktop, tablet, and mobile devices.
