# WEDE5020 – Website Development Project

## Overview

This repository contains my **WEDE5020 – Website Development** project for the IIE Diploma in IT (Software Development).

The project is the design and development of a responsive website for a **Seventh-day Adventist Church**. The website aims to provide visitors and church members with easy access to church information, ministries, events, Bible study registration, and contact details.
