# WEDE5020 – Website Development Project

## Overview

This repository contains the project work completed for the **WEDE5020 – Web Development** module.

At this stage of the project, the repository contains **two website proposals** prepared as part of **Project Initiation and Planning (Part 1)**. These proposals were created to demonstrate research, planning, analysis, and website design before development begins.

Following lecturer evaluation and approval, **one proposal will be selected** and developed into the final responsive website for the remainder of the module.

---

## Repository Contents

### Proposal A
**Seventh-day Adventist Church Website**

A proposal for a modern, responsive church website designed to improve communication with members and visitors by providing information about:

- Church information
- Ministries
- Worship services
- Bible study registration
- Events
- Community outreach
- Contact information

---

### Proposal B
**Ubuntu Paws Animal Rescue Website**

A proposal for a fictional non-profit animal rescue organisation website designed to:

- Promote animal adoption
- Recruit volunteers
- Accept sponsorship enquiries
- Share rescue stories
- Advertise events
- Allow reporting of stray or injured animals
- Improve public engagement

---

## Project Objectives

This module project aims to demonstrate the complete website development process, including:

- Client and organisation research
- Project planning
- Website proposal development
- User and stakeholder analysis
- Functional and non-functional requirements
- Information architecture
- Sitemap and navigation planning
- Wireframing
- UI/UX planning
- Responsive web design
- Front-end web development
- Testing and evaluation
- Version control using Git and GitHub
